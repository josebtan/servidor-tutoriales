# UnityCraft Web
Frontend en React + Vite con interfaz estilo Discord.
- `npm install` · `npm run dev` · `npm run build`
- `public/config.js`: IP, Discord y TikTok (editar aquí).
- `public/*.html`: tutoriales estáticos (protecciones, habilidades).
- `backend-api/`: backend en pausa (no se usa por ahora).
- Se publica con GitHub Pages desde `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).
